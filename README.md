# Планировщик задач (TODO-лист) — Дипломный проект

Веб-сервер на "Go" для управления списком задач с возможностью их циклического повторения.

## Как запустить проект локально

1. Установите зависимости в терминале:
   ```bash
   go mod tidy
   ```
2. Запустите сервер:
   ```bash
   go run .
   ```
3. Откройте в браузере: **http://localhost:7540**

*По умолчанию сервер создаст файл базы данных `scheduler.db` в корне проекта и займет порт `7540`. При желании порт можно изменить через переменную окружения `TODO_PORT`, а путь к БД — через `TODO_DBFILE`.*

## Как запустить тесты

1. Убедитесь, что сервер запущен в одном окне терминала (`go run .`).
2. В файле `tests/settings.go` проверьте параметры:
   - `Port = "7540"`
   - `FullNextDate = false` (задания повышенной сложности со звёздочкой не выполнялись).
3. Откройте второе окно терминала и запустите команду:
   ```bash
   go test ./tests/...
   ```

## Структура кода

Код разбит на логические пакеты для удобства проверки:
- `main.go` — точка входа и запуск веб-сервера.
- `pkg/db/db.go` — подключение к SQLite (`modernc.org/sqlite`), структура задачи и SQL-запросы.
- `pkg/api/` — обработчики REST API-запросов и логика вычисления следующих дат для задач.
- `web/` — готовые файлы фронтенда (HTML, CSS, JS).
